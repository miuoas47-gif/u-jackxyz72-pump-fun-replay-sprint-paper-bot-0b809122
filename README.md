Fresh-surge flipper: a paper trading bot for the pump.fun replay sprint. It trades 10 SOL of paper money on a replay of Solana chain data, buying small fixed stakes in new coins only when the recent tape shows real crowd buying (several distinct buyers, net SOL flowing in, price rising near its recent high), then flipping fast — take profit at +45%, stop loss at −30%, trailing stop, and a fade exit when the crowd turns seller. One shot per coin, so the run spreads across many coins. Paper money only; nothing is traded for real.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/replay/v2 on stdin/stdout: the harness sends `hello`, then one `batch` per slot, then `done`. It needs no arguments, no network, and no environment. Node 22.18+ runs the TypeScript as-is.
